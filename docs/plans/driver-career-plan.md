> 面向：负责实现的开发智能体
> 版本：v1（2026-11-07）
> 项目：《地平线狂飙：无尽公路》（Horizon Overdrive），`D:\AI项目集合\赛车游戏`

---

## 0. 为什么要做

**试玩反馈**：解锁摩托和警车之后就觉得无聊了，换车只能多撑一会儿。

**原因**：现在长线目标只有一条，就是“刷积分→买车/涂装/升级”。车一买完，玩家就没有下一个值得追的东西。热度、个人纪录、一次性成就这些都不是长期成长：热度每局清零，纪录只有数字，成就大约前 10 分钟就领完了。

**目标**：
1. 加一条**不靠花积分**的长线成长，也就是**车手等级（Lv 1～30）**，存在存档里，永不清零。
2. 加一层**短期目标**，也就是**任务（同时挂 3 个）**，让玩家每 1～2 分钟都有一个明确的小目标。
3. 用任务给已经买下的车**重新找理由去开**（某辆车专属的任务）。

**验收的体验指标**（用 §11 的节奏表自测）：
- 主流玩家第 2 分钟内第一次升级。
- 前 20 分钟内大约每 2～3 分钟升一级，到第 20 分钟大约 Lv 7～8。
- 任何时候，HUD 上都至少有 1 个任务能在 2 分钟内完成。

### 2.2 代码约定（必须遵守）

  3. 改完运行 `node --check assets/js/drive.js`；
  4. **不要**在 bash heredoc 里写 `\uXXXX` 转义（曾经因此把文件截断成 0 字节）。中文直接写 UTF-8 原文。

## 3. 核心循环

```
开一局 ──► 完成任务（+经验 +积分） ──► 升级（等级奖励：积分 / 称号 / 等级涂装 / 第 4 个任务位）
  ▲             │                                   │
  │             └── 任务里会要求换车、开某辆车       └── 第二期：解锁新的路上事件
  └──────────── 结算面板显示经验条和下一级奖励，引导“再来一局” ◄──┘
```

积分线保留原样：积分买车、涂装、升级。等级线是**并行的第二条线**，靠完成任务推进，不能用积分买。

## 4. 车手等级

### 4.1 经验曲线
- 升到下一级所需经验：`xpToNext(L) = 250 + 100 × (L − 1)`，L 为当前等级，取值 1～29。
- 最高 **Lv 30**。满级后经验继续累计，**每满 3,000 经验额外奖励 2,000 积分**，提示文案为「满级奖励」，这样满级之后仍然有回报。
- 存档只存**累计总经验** `career.xp`，等级由它推算，不要单独存等级。

## 5. 任务系统

### 5.1 规则
- **任务位**：3 个，Lv 12 起变成 4 个。任务**跨局保留**：死掉不会丢任务，只有「单局」类任务的进度会在新一局开始时清零。
- **两种范围**：
  - `run`（单局）：必须在一局里完成，`runStart` 时进度归零；
  - `total`（累计）：跨局累计。
- **完成**：进度达到目标时立刻发经验和积分、弹出提示；**1.5 秒后**在同一个任务位生成新任务。新任务的类型不能和其他任务位重复，也不能和刚完成的那个相同。
- **更换**：在车库等级页或开始界面，可以花 `300 × 档位` 积分换掉一个任务，需要二次确认，交互和性能升级的购买按钮一致。Lv 8 起每局开始前免费换 1 次。
- **新手引导期间**（`document.documentElement.dataset.tutorialActive === "true"`）：任务栏隐藏，任务进度不累计。
- **第一套任务固定**（新手引导毕业后、`career.xp === 0` 时）：
  1. 惊险超车 ×5（单局）
  2. 单局跑满 1 公里
  3. 撞飞 1 辆车（单局）

  目的是让第一次升级在 2 分钟内发生。

### 5.2 难度档与奖励

| 档位 | 出现条件 | 经验 | 积分 |
| :--- | :--- | ---: | ---: |
| T1 | Lv 1～4 全部 T1；Lv 5～14 有 30% 概率出 T1 | 120 | 300 |
| T2 | Lv 5～14 有 70% 概率出 T2；Lv 15 起有 50% 概率出 T2 | 220 | 600 |
| T3 | Lv 15 起有 50% 概率出 T3 | 360 | 1,000 |

### 5.4 存档结构（`boot.js` 模块 1 `installPlayerSettings`）

在 `DEFAULTS` 里新增：

| 键 | 类型 | 合并规则 | 说明 |
| :--- | :--- | :--- | :--- |
| `career.xp` | 非负整数 | **取最大值**：加入 `isMaxMonotonic` | 累计经验 |
| `career.reward.<L>` | 布尔值，L 取 2～30 | **只能 false→true**：加入 `isMonotonic` | 等级奖励是否已发放，保证多开标签页或云同步时只发一次 |
| `career.bonus` | 非负整数 | 取最大值 | 满级后已领取的「满级奖励」次数 |
| `missions.slots` | 数组 | 以最后一次写入为准，通过 `commit(fn)` 读改写 | 每项为 `{ id, tier, target, progress, scope, vehicle? }` |
| `missions.done` | 非负整数 | 取最大值 | 累计完成的任务数（统计用） |
| `missions.freeRerollRun` | 字符串 | 以最后一次写入为准 | 已使用免费更换的那一局的 id，防止同一局重复免费换 |

- `normalize()` 要校验 `missions.slots`：必须是数组，长度不超过 4；每项的 `id` 必须在任务池里，`tier` 是 1～3，`target` / `progress` 是非负整数，`scope` 是 `run` 或 `total`，`vehicle` 只能是合法车型 id。不合法的项直接丢弃，下次读取时补齐。
- 已有的 CrazyGames 云存档会通过 `flush` / `syncCloudData` 自动带上新的键，确认一下即可。
- **性能**：进度变化**不要每帧写存档**。在内存里累计，满足以下任一条件时才 `commit`：任务完成、`runEnd`、距上次写入超过 3 秒、`pagehide` 或 `visibilitychange`。

### 5.5 对外接口：`window.HorizonCareer`

```js
window.HorizonCareer = {
  info(),          // → { level, xp, cur, next, title:{en,zh}, maxed:boolean }，cur/next 是本级已有经验和本级所需经验
  missions(),      // → [{ slot, id, tier, scope, target, progress, vehicle, nameEn, nameZh, xp, pts, active }]，active 表示当前车型能否推进
  report(evt, d),  // 由 drive.js 调用，见 §6
  reroll(slot),    // → { ok, reason: 'rerolled'|'free'|'insufficient'|'locked', price }
  nextRewards(n),  // → 接下来 n 个有额外奖励的等级，给车库页用
  runSummary(),    // → { xpStart, xpEnd, levelStart, levelEnd, completed:[...] }，给结算面板用
};
```

每次状态变化时派发 `window.dispatchEvent(new CustomEvent('horizon-career-change', { detail }))`，UI 监听它刷新。

**调试**：只有 URL 带 `?debug=1` 时才挂上 `HorizonCareer.debug = { addXp(n), complete(slot), reset() }`。

## 6. 事件接入（drive.js → boot.js）

### 6.1 统一出口
`drive.js` 里现在有：

```js
const __hdAchv = (evt, data) => { … window.HorizonAchievements.report(evt, data) … };
```

把它改成同时调用 `window.HorizonCareer.report(evt, data)`（同样用 try/catch 包起来）。这样**只需要改这一个出口**，再在各处补上报点。成就模块 `report()` 不认识的事件会直接忽略，不需要改。

## 9. 第二期：随等级解锁的路上事件（可选）

第一期合并后再做，每个事件单独提交。所有事件共用一个调度器：每局从 1,200 米开始，每跑 1,000～1,500 米随机触发一个**已解锁**的事件，两个事件之间至少隔 600 米。同一时间只能有 1 个事件，猎隼的通缉车也算在内。

**第二期先做「街头飙车挑战」**（§9.1）。如果第一期还没合并，这个事件也可以先单独做：`window.HorizonCareer` 不存在时，就当作已解锁，从第一局就会出现。

### 9.1 街头飙车挑战（`street_race`，Lv 2 解锁）

**体验目标**：路上随机冲出一辆霓虹超跑，从后面追上你，在旁边挑衅几秒，然后越开越快地甩开你。你得开氮气、穿车流追上去反超它，赢了就有大奖。这是一个**可以无视**的挑战：不追只会被嘲讽，不会受罚。

#### 流程（4 个阶段）

| 阶段 | 时长 | 发生什么 |
| :--- | :--- | :--- |
| ① 登场 `approach` | 约 2～4 秒 | 用 `sE()` 在玩家**后方** 120～160 米、相邻车道刷出一辆 `persona: "racer"` 的超跑（车流里已经有这种 NPC：紫色或青色涂装，带 GT 大尾翼）。它以「玩家车速 + 60 km/h」追上来，同时闪两下远光（参照剧情模式追车的 `lightState.flashStart`），并按一次喇叭 `u.horn(.42,"jet")`。HUD 提示「🏁 后方有车来挑战！」 |
| ② 挑衅 `taunt` | 2 秒 | 它开到与玩家并排的位置（横向相隔 1 条车道，z 方向相差在 ±3 米内），**速度和玩家保持一致**，并冒出挑衅气泡：从 `NPC_DIALOGUE_POOL.racer` 的 `taunt` 里随机挑一句，或者用固定文案「就这速度？追得上我再说！」/「That all you got? Catch me!」 |
| ③ 飙走 `race` | 最长 30 秒 | 它开始加速，**速度越来越快**（见下面的速度曲线），频繁变道穿过车流，并且无视红灯。HUD 显示状态条 `.street-race-status`：「🏁 飙车 24 秒 · 落后 85 米」，领先后变成「领先 20 米」 |
| ④ 结算 | — | 胜负判定见下文；结算后它会减速并汇入车流，5 秒后移除挑战标记 |

#### 速度曲线（“越来越快”）
- 挑战开始时的速度：`v0 = max(160, 玩家车速) + 40` km/h。
- 每秒提速 `+6 km/h`，直到达到上限 `cap`。
- 上限：`cap = Mn.nosTopSpeed − 15 − (5 − 段位) × 10` km/h，按**玩家当前车型**的氮气极速来算。例如轿跑 1 段位时上限是 355 − 55 = 300 km/h，5 段位时是 340 km/h。结果是：不开氮气基本追不上，开氮气才能追近，段位越高越难。
- **被反超后会恼羞成怒**：玩家领先它时，它的目标速度临时 +20 km/h，持续 3 秒，冒出气泡「别得意！」，并会尝试再超回来。这样比赛会有来回拉锯。
- 实现方式和通缉车一样：在 NPC 速度计算里，用 `Math.max(Hg(...), 飙车目标速度)` 覆盖它的速度；加速度提高到 14 m/s²；`stopGap` 视为无穷远（无视红灯）；前方 35 米内有车就立即变道。这些代码可以直接参考 `__hdPur` 那一段，建议抽成一个“逃跑 NPC”的公共辅助函数，通缉车和飙车共用。

#### 胜负判定

| 结果 | 条件 | 奖励 / 后果 |
| :--- | :--- | :--- |
| **胜利** | 玩家领先它 ≥ 40 米（`它的 z − 玩家 z ≥ 40`） | **+1,200 基础分**（乘热度倍率）、氮气 +50%、热度直接升 1 级，段位 +1（最高 5）；HUD 提示「🏁 飙车胜利！」；它冒出气泡「下次再比！」后退场 |
| 失败：被甩掉 | 它领先玩家 ≥ 450 米 | 没有惩罚，连击**不清零**；HUD 提示「💨 对手扬长而去」 |
| 失败：超时 | 30 秒内没有满足胜利条件 | 同上 |
| 中止 | 玩家撞毁、本局结束、进入隧道或分岔路口 | 静默结束，不提示 |

- **段位**：存档键 `race.tier`，取值 1～5，按取最大值合并。每赢一次 +1，输了不降。段位越高速度上限越高，奖励也越高：`1,200 + 300 × (段位 − 1)`。
- **不能直接撞飞对手**：比赛期间把它设为 `body.tossProtected = true`，防止玩家一撞了事；正常碰撞照常扣血，这也是比赛的风险。
- **飞车**：可以起飞追它，6 秒的飞行时间本身就是限制，不需要额外处理。
- **猎隼**：可以照常参赛，但飙车和通缉车不会同时出现（调度器保证）。

#### 出现条件
- 由第二期调度器随机触发。第一期没合并时，用单独的里程计数器：从 1,500 米开始，每 1,800～2,600 米触发一次。
- 刷新前检查：玩家车速 ≥ 120 km/h；后方 200 米内没有横穿车辆；当前路段不是隧道 `tunnel` / `deepTunnel`，也不是分岔 `fork`（可参考弧形坡道曾用过的路段检查：`yn(距离, x.route).kind`）；猎隼的通缉车不在进行中；现有的挑衅机车 `wA` 不在挑衅状态（`wA.motorcycle.taunted` 为 false，或者已经过了 `until`）。
- 新手引导期间不出现。

#### 界面
- 对手车头顶挂一个「🏁 RIVAL / 🏁 挑战者」标记精灵，做法和通缉车标记 `__hdWantedSprite` 一样，颜色用紫青交替。切换语言时要重绘：另一个智能体已经给通缉车标记加了 `sp.redraw`，照着做。
- HUD 状态条 `.street-race-status` 放在顶部中央，复用 `.police-wanted-status` 的位置和样式，换成紫色描边；领先时数字变绿，落后时是白色。两个状态条不会同时出现。
- 胜利时调用 `u.stinger("record")` 播放上行琶音，并调用 `HorizonCrazyGames.happytime()`。

#### 上报事件和任务
- 新增上报：`__hdAchv("raceStart")`，以及 `__hdAchv("raceEnd",{won:true|false,tier})`。
- 任务池新增两种任务：
  - `race_win`「赢得飙车挑战 N 次 / Win N street races」，累计，目标 1 / 2 / 4；
  - `race_lead`「飙车中领先 N 米 / Lead a race by N m」，单局，目标 40 / 80 / 150。
- 一次性成就新增：`race_win_1`「首次赢得飙车挑战」，奖励 800。
